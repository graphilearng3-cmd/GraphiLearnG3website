About GraphiLearn

A proposed web-based tutorial platform for the BTLED Industrial Arts Program.

Project Overview

Graphi & Learn is a proposed web-based tutorial platform developed to support the learning of graphic design creation using Adobe Photoshop for the BTLED Industrial Arts Program.

The website brings together practical tutorials, Photoshop tool references, and shortcut keys to help learners explore graphic design techniques.

Purpose of the Website

The website aims to provide an organized learning resource where students can follow practical, step-by-step lessons and refer to common Photoshop tools and shortcut keys.

It is intended to support classroom instruction and independent practice while encouraging learners to create and edit their own graphic designs.

Scope of the Content

  • Ten practical Adobe Photoshop tutorials focused on creating and editing graphic designs.
  • Twenty-four Photoshop tools arranged into six categories, with definitions and beginner-friendly instructions.
  • A reference list of common Photoshop shortcut keys.
  • Visual examples and recorded video demonstrations prepared by the project team.

Development Technologies

HTML is used to structure the website pages and content. CSS is used for the visual design, navigation, layout, and responsive presentation. The website is built using HTML and CSS only, without JavaScript or database integration.
