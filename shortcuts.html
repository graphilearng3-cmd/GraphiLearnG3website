Quick Reference

Adobe Photoshop Shortcut Keys

A quick reference for common keyboard shortcuts on Windows.

Important: These are common default Windows shortcuts. Some shortcuts may differ by Photoshop version, keyboard layout, selected tool, or customized settings. On macOS, many Ctrl shortcuts use Cmd instead.

File and Editing

Action Shortcut
New document Ctrl + N
Open Ctrl + O
Save Ctrl + S
Save As Ctrl + Shift + S
Close document Ctrl + W
Undo Ctrl + Z
Step backward Ctrl + Alt + Z
Step forward Ctrl + Shift + Z
Cut / Copy / Paste Ctrl + X / C / V
Select all Ctrl + A
Deselect Ctrl + D
