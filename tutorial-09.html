About This Lesson

Construct a simple logo using shapes, text, alignment, and a limited color palette. The steps below use common Photoshop tools and panels; labels may vary slightly by version.

Learning Objectives

At the end of the activity, learners should be able to:

  • Identify and use the basic tools in Adobe Photoshop to create a logo.
  • Create a simple and creative computer logo using shapes, images, and colors.
  • Apply proper resizing, positioning, and color adjustments to produce a neat and attractive logo.

Step-by-Step Instructions

  1. Step 1

    Open Adobe Photoshop

  2. Step 2

    Create a New Document

  3. Step 3

    Select the Ellipse Tool and Create a Circle

  4. Step 4

    Add the Image

  5. Step 5

    Resize and Position the Image

  6. Step 6

    Add a Circular Outline and Adjust the Colors

  7. Step 7

    Save the Logo
